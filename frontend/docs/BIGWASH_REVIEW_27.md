# BigWash — реєстр 28 зауважень від 17.11.2026

Оновлено 21.11.2026 за поточними вихідними файлами та регресійними перевірками. Це один актуальний реєстр; попередні проміжні підсумки замінено поточними статусами.

- **FIXED** — виправлення frontend перевірено; це не підтвердження сумісності зі справжнім Go API.
- **FIXED_DEV** — перевірено локальну DEV-реалізацію; серверне збереження або виконання обладнанням не підключено.
- **BLOCKED_BACKEND** — потрібен відсутній контракт Go API або обладнання.
- **NEEDS_CLARIFICATION** — для завершення потрібне конкретне рішення власника.
- **NOT_FIXED** — підтверджена невиправлена недоробка frontend.

## Додаткові межі передачі

- Реальний Go, платежі, WebSocket-події обладнання, доставка Telegram і SQL-backup не проходили інтеграційного тестування. Production-preview використовує лише тестову імітацію наявних маршрутів з API_CONTRACT.md.
- Створення/видалення самих пультів, копіювання програм між пультами та частина платіжних налаштувань Service залишаються непідключеними елементами інтерфейсу. Їх не оголошено серверними функціями. Загальний каталог програм та журнал операцій використовують браузерні дані; Go-контракти для них потрібно погодити.
- Адаптивність перевіряється браузерними тестами на мобільних і десктопних ширинах, UA/RU та обох темах. Попередню перевірку справжнього Moto G60 через ADB (таблиця, клавіатура, скасування, F5) не підмінено емуляцією; у фінальному аудиті нових перевірок на самому телефоні не виконували.
- HTTPS LAN перевіряється на окремих тестових серверах і сертифікатах, без зміни системного довірчого сховища. Встановлення CA на конкретному телефоні потребує ручної перевірки власника.
- `npm run check` потребує відсутніх svelte-check/jsconfig.json. Пакети не встановлювалися. Залишаються попередні попередження Svelte, відсутній favicon.ico та вибір production-адаптера. Linux-запуск окремо не перевірено; регістр імпортів перевіряється автоматично.
- Старий статичний образець API-ключа Service прибрано з поточного коду. Якщо це був справжній ключ, його слід відкликати/замінити; історію Git не переписували.

## Перевірки

Постійні регресії знаходяться в `tests/*.test.mjs`: DEV/PROD та сесії, LAN/Web Crypto, UA/RU, статичні/динамічні ключі, CRUD і форми, медіа/XSS/IndexedDB, USB, реле, карта, знижки, Promo, мобільні компоновки, безпечний JSON-експорт і Git-ignore. Запуск — послідовний, з ізольованими профілями Chrome; параметри наведено в README.md. Порівняльний знімок перекладів і таблиця старих/нових ключів зберігаються лише поза репозиторієм.
